
# 4개 ESP32 신호등 연동 시스템

## 구성
- ESP32 4개: 각 보드가 신호등 1개 제어
- PyQt 관제 1개: 4개 ESP32를 동시에 관리
- 통신: Wi-Fi TCP 소켓

## 핵심 동작
### 자동 모드
순서:
1번 -> 2번 -> 3번 -> 4번 -> 1번 반복

동작:
- 현재 신호등 G 유지
- 시간이 끝나면 현재 신호등 Y
- Y 시간이 끝나면 현재 신호등 R
- 다음 신호등 G

즉, 항상 초록불은 1개만 켜집니다.

### 수동 모드
- 신호등 1~4를 각각 개별 제어 가능
- R / Y / G / OFF 가능
- R 점멸 / Y 점멸 가능

### 반자동 모드
- 현재 초록불이 있는 상태에서 다른 신호등에 초록을 주면
  현재 초록불 -> 노랑불 -> 빨간불 -> 대상 신호등 초록불
- 현재 초록불이 없으면 대상 신호등을 바로 초록으로 바꿉니다.

## ESP32 설정
`esp32_traffic_light_node.ino`를 각 보드에 업로드하세요.

보드마다 아래만 바꾸면 됩니다.

```cpp
#define DEVICE_ID 1
```

각 보드별:
- 1번 보드: DEVICE_ID 1
- 2번 보드: DEVICE_ID 2
- 3번 보드: DEVICE_ID 3
- 4번 보드: DEVICE_ID 4

그리고 Wi-Fi 정보도 수정하세요.

```cpp
const char* WIFI_SSID     = "YOUR_WIFI_SSID";
const char* WIFI_PASSWORD = "YOUR_WIFI_PASSWORD";
```

---

## 핀 연결 예시
- R -> GPIO 25
- Y -> GPIO 26
- G -> GPIO 27
- GND -> ESP32 GND

램프 전류가 크면 MOSFET/트랜지스터/릴레이 드라이버를 사용하세요.

## PyQt 실행
필요 패키지 설치:

```bash
pip install pyqt6
```

실행:

```bash
python traffic_light_4way_gui.py
```

---

## 연결 절차
1. ESP32 4개를 모두 업로드 후 실행
2. 시리얼 모니터에서 각 ESP32 IP 확인
3. PyQt에 1~4번 IP 입력
4. 각 신호등 연결 버튼 클릭
5. 자동 또는 수동/반자동 모드 사용

---

## 권장 운용 규칙
- 연동 신호 체계에서는 동시에 여러 개를 초록으로 두지 않는 것이 안전합니다.
- 그래서 GUI에서는 한 신호등을 G로 강제 지정하면 나머지는 자동으로 R로 바꿉니다.
- 점멸은 개별 유지보수/고장 모드처럼 사용할 수 있습니다.
