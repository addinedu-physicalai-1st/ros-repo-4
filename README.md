# ARASEO 프로젝트

## 프로젝트 개요
ARASEO 프로젝트는 완전 자율주행 택시 서비스의 전 과정을 관리하는 통합 플랫폼입니다. 
* 시스템은 맵 전역에 택시를 균등하게 사전 배치하여 빠른 호출에 대응하며, 사용자는 모바일로 간편하게 호출 및 요금 결제를 수행할 수 있습니다. 
* 차량은 최적 배차 및 자율 주행 알고리즘을 통해 목적지까지 교통 수칙을 준수하며 주행합니다. 
* 택시의 배터리가 30% 이하로 떨어지면 자동으로 무인 충전에 돌입하며, 차량 고장이나 해킹 등 긴급 상황 발생 시 즉시 안전 정차를 수행하여 높은 신뢰성을 보장합니다.

## 시스템 아키텍쳐

![시스템 아키텍쳐](./Software%20Architecture.png)

* **UI 계층**: 승객이 사용하는 모바일 앱(UserGUI)과 시스템 관리자가 관제탑으로 사용하는 PC 대시보드(AdminGUI)로 구성됩니다.
* **Server 계층**: 웹 서비스와 실시간 관제 로직, 데이터베이스(DB)를 관리하는 Operation Server와 자율주행 연산 및 명령을 전담하는 AI Server로 분리되어 부하를 분산합니다.
* **Device 계층**: 물리적인 현장 하드웨어입니다. 맵핑을 담당하는 GPS Kit, 차고지 출입 및 자동 충전을 관리하는 Hub Kit, 그리고 카메라와 LiDAR 등 핵심 센서를 탑재한 5대의 Taxi Kit로 구성되어 실제 명령을 수행합니다.
