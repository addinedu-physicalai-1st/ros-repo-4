 
================================================================================
  dalimi_GPS_GUI3 + GPSTopicTest 실행 순서
================================================================================

1) dalimi_GPS_GUI3 실행 (WebSocket 클라이언트 — ArUco 마커 검출 + GPS 좌표 전송)
--------------------------------------------------------------------------------
   cd /home/ghlee/tmp_cursor_project2/dalimi_GPS_GUI3
   python3 -m dalimi_gps_gui3


2) GPSTopicTest 빌드 및 환경 설정
--------------------------------------------------------------------------------
   cd /home/ghlee/tmp_cursor_project2/GPSTopicTest
   source /opt/ros/jazzy/setup.bash
   export ROS_DOMAIN_ID=204
   colcon build
   source ./install/local_setup.bash


3) ws_gps_publisher 실행 (WebSocket 서버 → ROS2 토픽 발행)
--------------------------------------------------------------------------------
   ros2 run gps_field_ws_bridge ws_gps_publisher \
     --ros-args \
     -p pinky_ids_env_file:=.env \
     -p pinky_ids_env_filter_by_pinky_id:=true


4) field_gps_subscriber 실행 (ROS2 토픽 구독 → Tkinter 화면 표시)
--------------------------------------------------------------------------------
   ros2 run gps_field_subscriber field_gps_subscriber \
     --ros-args \
     -p pinky_id:=14 \
     -p show_tk:=true \
     -p show_oled:=false


================================================================================
  통신 흐름
================================================================================

  dalimi_GPS_GUI3         ws_gps_publisher           field_gps_subscriber
  (ArUco 검출)     →      (WS 서버 + ROS 발행)  →    (ROS 구독 + 화면 표시)
                ws://127.0.0.1:8765         /pinky_34/gps_pos

================================================================================
  참고(tmp info)
================================================================================
- ROS_DOMAIN_ID=204 는 3), 4) 단계에서 동일하게 설정해야 함
- .env 파일(GPSTopicTest/.env)에 PINKY_GPS_PUBLISH_IDS=14,24,34,45,54,64 설정 필요
- 1)번은 별도 터미널에서 먼저 실행해야 WS 연결이 성립됨
- 3), 4)번은 같은 터미널에서 순서대로 실행하거나 각각 별도 터미널에서 실행
  (별도 터미널일 경우 각 터미널에서 source 및 export ROS_DOMAIN_ID=204 필요)
