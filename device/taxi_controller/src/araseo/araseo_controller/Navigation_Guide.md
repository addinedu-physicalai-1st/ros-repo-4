# Lane Navigation System v0.20 제어 가이드

본 문서는 Lane_CPP_raspi 시스템의 최신 단축키 및 제어 로직을 정리한 문서입니다.

## 1. ROI (인식 영역) 제어
상/하단 영역을 독립적으로 조절하여 가상 공간(화면 밖)까지 추적할 수 있습니다.

| 기능 | 상단(Top) | 하단(Bottom) |
| :--- | :--- | :--- |
| **높이/위치** | `w`(위), `s`(아래) | - |
| **너비(폭)** | `h`(좁게), `j`(넓게) | `n`(좁게), `m`(넓게) |
| **좌우 이동** | `a`(좌), `d`(우) | `z`(좌), `x`(우) |

*   **`g` 키**: **Adaptive ROI (자동 너비 조절) ON/OFF 토글**

## 2. 주행 및 상태 제어
| 단축키 | 기능 | 설명 |
| :--- | :--- | :--- |
| **`v`** | **AUTO/MANUAL 전환** | 자율주행 모드 토글 |
| **`i` / `k`** | **속도 Up / Down** | 설정 속도 조절 |
| **`u` / `o`** | **조향 오프셋** | 미세 조향 중심점 조절 |
| **`r`** | **파라미터 초기화** | 모든 ROI 및 속도 설정 초기화 |
| **`Space`** | **비상 정지** | 즉시 속도 0 및 정지 |

## 3. 시스템 및 시각화
| 단축키 | 기능 | 설명 |
| :--- | :--- | :--- |
| **`e`** | **로그 ON/OFF** | 터미널 상태 출력 토글 |
| **`1` / `2`** | **정지 거리 조절** | 라이다 장애물 정지 거리 (- / +) |
| **`?`** | **도움말** | 단축키 목록 출력 |
| **`p`** | **Lidar PIP** | 레이더 맵 보기 |
| **`b`** | **BEV PIP** | 상단뷰(Bird's Eye) 보기 |
| **`c`** | **Camera PIP** | 원본 카메라 영상 보기 |
| **`t` / `[`** | **임계값 조절** | 차선 필터링(White Threshold) 조절 |

## 4. 특징 (Virtual ROI)
*   `x` 키 등을 통해 하단 너비를 화면 밖으로 확장하면 검은색 여백에 빨간색 ROI 선이 나타납니다.
*   가상 공간의 차선을 인식하여 급커브에서도 안정적인 주행이 가능합니다.
